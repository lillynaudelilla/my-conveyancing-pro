# My Conveyancing Pro — GitHub Pages

Public static pages for Google Play privacy, account deletion and support.

Files:
- `index.html`
- `privacy.html`
- `delete-account.html`
- `support.html`
- `assets/style.css`

The support email is `Lillynaude.Lilla@gmail.com`.

Publish with GitHub Pages from the `main` branch and repository root, or use the included GitHub Actions workflow.

Do not put passwords, Supabase service-role keys, database credentials, or private signing keys in this repository.

The deletion page currently accepts requests by email. For automated deletion, connect it to the Supabase account-deletion endpoint before launch.
